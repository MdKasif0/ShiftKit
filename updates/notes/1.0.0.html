ShiftKit 1.0.0 Release

Initial release of ShiftKit — the local-first radial file action utility for macOS.

  • Signature Radial Menu: Hold Shift while dragging files in Finder to trigger the radial action wheel at your cursor.
  • Universal Media Operations: Convert, compress, crop, trim, and merge images, audio, video, and PDF documents.
  • 100% On-Device: Zero network uploads, zero telemetry, full privacy guarantee.
  • Automatic Updates: Powered by Sparkle 2 with EdDSA cryptographic verification.
